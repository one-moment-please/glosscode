G-Code Reader for Windows

This is a working mockup of the Windows app. Every word sits in a fixed-width column with its English word directly above it. You can edit either line, and changes to one update the other.

Line colors

Each line gets a colored bar from the motion mode that's active when it moves: amber for rapid, blue for straight feed, teal for arcs and magenta for drilling cycles. Rapid lines also get a warm tint, so a rapid near the part stands out. Lines that don't move have no bar.

Active modes

The panel shows every mode that's in effect on the selected line: motion, units, positions, plane, feed mode and rate, spindle, coolant, tool, offsets and work offset. A red dot marks modes set on that line, so you can see which line turned each one on.

Z by line

The timeline gives each line, in the order the machine runs it, one step showing the Z height after that line. The selected line sits on the center mark and the strip slides as you move. Subprogram lines appear every time they're called, so both rectangle passes show. Heights above Z0.3 are drawn at the top with an arrow. Click a step to jump to its line.

Automatic N numbers

With Auto N on, a new line gets the next free number counting by 10, or the midpoint when there's no room, like N75 between N70 and N80. When there's no gap at all, the status bar says so and Renumber respaces the main program by 10. Subprogram labels are left alone so their calls keep working.

Subprograms shown inline

A call like N100 M97 P1000 gets a ▸ show N1000 button. It inserts the subprogram's lines between the call and the next line. Those rows have a purple bar, a ↳ in the margin and purple N numbers, so they never look like part of the main program. Editing an inserted row edits the subprogram itself, so every call sees the change. The toolpath follows the calls too, which is why the rectangle is cut at two depths.

Fixed-width columns

Every column is the same width: 10 characters in Long mode and 8 in Short mode. Words line up down the whole file, not just within one line. The rare word that doesn't fit is cut off with an ellipsis, and hovering shows it in full. Column width can be a setting.

Two ways to edit

In G-code mode you type codes and the English updates. In English mode you type words like COOLON or RPM600 and the G-code is written for you. The file only ever stores G-code. If a word clashes with the active mode, like IPR25 while G94 is on, the status bar says so.

Autocomplete

Suggestions come from the dictionary plus the selected machine's file, so a Haas mill offers TSCON (M88) and a Fanuc mill doesn't. Matching works on the word, the code or the description, so typing coolant also finds COOLON.

Standard file dialogs

Open and Save call the real system dialog from C. On Windows that's IFileOpenDialog, and on Linux it's the GTK or desktop-portal dialog. The nativefiledialog-extended library wraps both behind one call. An HTML file input would also show the Windows dialog, but it hides the file's real path, so Save couldn't write back to the same file.
