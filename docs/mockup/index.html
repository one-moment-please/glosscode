GlossCode for Windows

This is a working mockup of the Windows app. Every word sits in a fixed-width column with its English word directly above it. You can edit either line, and changes to one update the other.

Menus, not a ribbon

Every command lives in the menu bar with its shortcut shown, so there's no separate toolbar. That leaves the most room for code. The only controls outside the menus are the Edit, Show and Layout toggles above the editor, and the machine picker at the right end of the menu bar.

Machine profiles

The machine picker lists recent machines first, then the other profiles. Edit this profile… or New machine profile… opens the profile editor: name, control, dialect, mill or lathe, travel, spindle and feed limits, tool pockets, and the brand's own codes. Each profile is saved as one JSON file in a machines folder, and the logic checks read their limits from it.

Sort words

Program › Sort words puts every line in one fixed order: N, setup G-codes, motion, X, Y, Z, I/J/K/R, F, S, T/H/D, M, others, then the comment. On Fanuc-style controls the order of words in a line doesn't change what it does, so sorting is safe there. Each sort can be undone in one step.

Columns by word type

This layout gives each word type its own column, so X values are always under X and M-codes always sit together. Only the columns a file actually uses appear. Rare words go in an Other column near the end, so there are no rows of empty columns. Click an empty cell to add a word of that type in the right place.

Simulation and preview

▶ plays the program one move at a time. The editor follows along, and the tool marker shows where the cutter is. When you're not playing, moves after the selected line are greyed out, or hidden if you choose that in View. View › Toolpath colors › By tool gives each tool its own color, like the spot drill (T2) here.

Subprograms shown inline

A call like N100 M97 P1000 gets a ▸ show N1000 button. It inserts the subprogram's lines below the call, with a purple bar, a ↳ in the margin and purple N numbers. Editing those rows edits the subprogram itself.

Problems panel

Every rule lives in gcode-rules.json: its message, its severity and the per-control tables it reads, such as which words each canned cycle needs on Haas, Fanuc or Okuma. A machine file can raise, lower or turn off any rule. The checks walk the program in the order the machine runs it, so a subprogram is checked with the feed, spindle and offsets active at its call.

Decimals and units

The English line always shows the decimal point, so X1. reads X1.0. A distance word with no decimal point, like X1, reads X0.0001 in orange, because that's how a Fanuc-style control takes it, and the Problems panel flags it. Feeds and speeds keep their letter and get a small unit: F12.0ipm, S2500rpm, S400sfm.

Keyboard editing

← → move between words and ↑ ↓ between lines. Enter edits the selected word and Enter again finishes it, leaving it selected. While editing, Space starts a new word to the right; in G-code, typing the next letter does too (G01X becomes G01 and X). Shift+Enter breaks the line after the selected word. Caps Lock switches between the G-code and English lines, since everything is in capitals anyway.

Words a code still needs

After a code that needs more words, grey hint text shows them: G02 gets R## or I## J##, G83 gets Z## R## Q##. Click R## (or select it and press Enter) and the R is typed for you; the I and J hints go away. Pick I## instead and R goes away but J stays. The lists come from the same tables as the checks, per control.

Insert menu

Hole pattern… works out drilling positions for a grid or a bolt circle. The canned cycle entries are grouped the way you'd look for them: drilling, tapping and boring on a mill; roughing, finishing, turning and facing, grooving, threading and live tooling on a lathe. Each opens a window with a rough sketch, a box for each word, and the finished line with its English. A category the machine can't run, like live tooling on a lathe without it, isn't listed, and the menu says what's hidden.

Subprogram library

Insert › Subprogram library… keeps routines you reuse across programs, like a slot where only the positions and depth change. Fill in the values and insert it as one G65 P9101 line, or as plain lines worked out from the values for a control without the macro option. The call reads SLOTMILL with each value by name, and ▸ show lists what it runs in green. Try SLOTS_PLATE.nc.

Canned cycle guide

F1 on a cycle, or How G76 works… in the side panel, opens a page for that cycle: a rough sketch of how it moves, an example line using every word it takes with the English above it, and a table of what each word does and whether it's needed. Start a new line with this cycle adds the code and lets the hints walk you through the rest.

End of block

Many older controls need ; at the end of every line. Each machine profile has an End of block setting. When it's on, every line shows a ; after an empty word space, and Save writes it. Files that already use ; are read correctly on any machine. Try BRACKET_0MC.nc, set up for a Fanuc 0-MC.

Standard file dialogs

Open and Save call the real system dialog from C: IFileOpenDialog on Windows, and the GTK or desktop-portal dialog on Linux. The nativefiledialog-extended library wraps both behind one call.
